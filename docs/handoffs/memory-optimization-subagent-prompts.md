# 内存优化任务卡（2026-10-16 修订）

仅在用户明确要求委派时分发，本文不自动授权子智能体。依据 window-memory-states.md；旧 1240 MB、12s 和放宽退役时间建议废止。

## 公共约束

读 AGENTS.md、当前三状态设计和直接相关代码。可见未聚焦退役及退役时间已定，以代码为准，不修改时间来换内存数字。保持分区隔离及现有保护。最小态<70MiB，标准态刚启动整树<300MiB，一个完整主窗热呼出无重载，十非浏览器主窗≤1GiB，十浏览器≤5GiB，游戏按真实模式另验。构建/打包态指定根PID整树总工作集含共享页，测峰值及窗口/网页身份；禁止用仅Tab、空页、已退役窗口冒充完整场景。用户已授权在低内存模式中内置自身进程工作集清空，必须对照启用/禁用并同时记录私有提交与回涨；禁止用外部清理工具代替内置策略，或只报清理后的最低值。构建前与会话结束 clean:budget。

## A：只读归因

- A-01 最小驻留：启动/快捷键/edition-session 边界，原生轻宿主启动与持久化时序；不把隐藏当最小态。
- A-02 十壳入口：真实主窗多实例、浏览器转换、公共资源与状态隔离；缺入口报未实现。
- A-03 GPU峰值：同网页同尺寸分析纹理回收与重复加载，提出可复测候选修改。
- A-04 测试可信度：整树漏计、身份下降、峰值、物理快捷键、页面运行态；mock通过不等于真机。

## B：真机，容量测量串行

- B-01 standard：受控页及真实输入/切换，窗口与网页不重载，物理键盘P50/P95/最大延迟；既有到期退役另测。
- B-02 browsers：本地页与真实AI页分别测，十窗十页都就绪，全部宿主/后代计量，记录建窗/切换/还原峰值。
- B-03 minimum/shells：生产入口缺失报BLOCKED；原生宿主和十真实主窗接入后才跑最终验收。

## C：实现，按依赖

- C-01 轻宿主原型：只驻留唤出与会话，真实<70MiB、无孤儿、启动单例；标准热态和既有退役保留。
- C-02 十主窗壳：真实多实例壳及浏览器转换，共享配置/资源、隔离状态；验收≤1GiB。
- C-04 标准态启动：整树<300MiB；以默认AI页和Kimi复测，保留操作能力与热呼出；优先验证原生焦点桥、GPU和双renderer成本。分包/词典已有修正，但实测仍超限。
- C-03 十浏览器峰值：依据GPU/壳实测改善，不卸每窗唯一页，不改退役时间；同场景前后对比。
