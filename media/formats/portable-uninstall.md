# 绿色包便携卸载契约

本文定义绿色包（便携包）的识别方式、随包清单格式与卸载范围规则，供独立实现卸载工具时直接依据。官方维护向导以二进制组件形式提供，其行为与本文一致；本文只描述包与卸载器之间的公开约定，不授予任何发行信任。

## 当前包型

概念版绿色包按架构拆分：x64 与 ARM64 各自一个 ZIP。ZIP 内只有一层 `SidekickAI/` 目录，它既是应用目录也是安装根——`SidekickAI.exe` 位于该目录根部，用户数据目录 `data` 位于同一目录内，没有并列运行目录、启动器脚本或布局契约文件。

因此卸载的删除范围是：安装根本身，以及安装根内声明的数据根。卸载器不需要在包外寻找任何目录。

## 识别绿色包

绿色包是免安装的完整应用目录。安装根（用户解压后得到的目录）包含两个必需文件：

| 文件                        | 内容            | 作用                   |
| --------------------------- | --------------- | ---------------------- |
| `portable.txt`              | 固定 `portable` | 标记该目录是绿色包     |
| `maintenance/portable.json` | 便携清单        | 声明卸载范围与数据位置 |

标记文件内容固定为 `portable`，不带 BOM 与其它内容。只有 `portable.txt` 而没有 `maintenance/portable.json` 时，该目录没有可验证的安装身份：卸载器必须拒绝提供“删除全部内容”的正常卸载路径，不得猜测数据位置，也不得把未声明的用户目录当作可删除目标。

## 便携清单

`maintenance/portable.json` 是无 BOM 的 UTF-8 JSON。对象不得包含重复或未知字段。

| 字段          | 类型   | 含义                         |
| ------------- | ------ | ---------------------------- |
| schemaVersion | 整数   | 固定为 1                     |
| kind          | 字符串 | 固定为 `portable-manifest`   |
| product       | 对象   | 产品身份                     |
| rootOwned     | 布尔   | 安装根是否整体归该绿色包所有 |
| dataRoots     | 数组   | 数据根清单                   |
| registrations | 数组   | 注册表与快捷方式登记         |

| product 字段 | 类型   | 含义                                           |
| ------------ | ------ | ---------------------------------------------- |
| productId    | 字符串 | 产品路线标识；概念版为 `sidekickai-opensource` |
| version      | 字符串 | 产品版本                                       |

| dataRoots 元素字段 | 类型   | 含义                                        |
| ------------------ | ------ | ------------------------------------------- |
| scope              | 字符串 | `install-root`、`appdata` 或 `localappdata` |
| path               | 字符串 | 相对该作用域根的目录路径                    |
| recursive          | 布尔   | 固定为 `true`，目录整体递归删除             |

## 数据根规则

- 写在安装目录内的数据声明 `scope=install-root`，`path` 为相对安装根的路径。
- 写在用户目录的数据声明 `scope=appdata` 或 `scope=localappdata`，`path` 为相对该根的单段目录名。
- 不接受绝对路径、盘符、`..` 或越界路径。
- 声明的是目录而不是单个文件：卸载时递归删除，导入后新生成的文件同样被清除。

## 安装根归属

- `rootOwned` 为 `true`：整个安装根归该绿色包所有，卸载时删除根目录及全部内容。
- `rootOwned` 为 `false`：只删除清单声明的文件与数据根，安装根为空时才删除根目录。若绿色包会把用户文件放进安装根，必须使用 `false` 并列出属于包的文件。

概念版绿色包的用户数据全部写在安装根内的 `data` 目录，因此声明 `rootOwned` 为 `true`，数据根只声明 `install-root` 的 `data`；卸载不涉及任何用户目录。

## 注册表与快捷方式

绿色包不写注册表与快捷方式。若写入，必须在 `registrations` 中声明，否则卸载器不能承诺“全部卸载”，只能按已声明范围清理。

## 卸载流程

1. 扫描安装根，读取 `portable.txt` 与 `maintenance/portable.json`；两者缺一即拒绝正常卸载。
2. 校验清单格式、产品身份与数据根路径规则，任一不合规则拒绝，不做修补或推断。
3. 展示将删除的内容：包内文件、安装根内的数据根，以及清单声明的注册项。
4. 用户确认后按清单删除：先删除数据根，再按 `rootOwned` 处理安装根。

未声明的目录与安装根之外的用户文件不在删除范围内。

## 导入要求

导入或解压绿色包时必须原样保留 `portable.txt` 与 `maintenance/portable.json`，不得改写、替换或丢弃。导入方应按上述规则核对这两个文件的字节，缺失或被改写时按没有可验证安装身份处理。
