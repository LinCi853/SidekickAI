# 工百窗 / SidekickAI

> 全平台 AI 聚合 · 安全 · 安静 · 随意

多 AI 平台聚合到一个桌面应用，多 Profile 隔离多账号登录，配合提示词注入、全局热键与后台语音，构建沉浸免打扰的本地 AI 工作流。

## 设计理念

- **聚合**：内置多家 AI 平台预设，同一平台可同时登录多个账号；支持自定义 AI Provider 接入
- **安全**：语音识别基于本地 `whisper.cpp`，数据不出本机；密钥通过系统密钥库加密存储；对话记录本地落库
- **安静**：自动屏蔽 AI 平台的下载引导、升级横幅、原生弹窗；干扰元素三层拦截，登录弹窗智能白名单
- **随意**：`Alt+V` 随时语音提问、`Alt+Q` 切换窗口、全局热键键盘流操作、提示词三段注入实时预览，不打断当前思路

## 主要功能

### AI 平台聚合

- **内置多家 AI 平台预设**：Kimi、DeepSeek、智谱清言、豆包、通义千问、文心一言、ChatGPT、Claude、Gemini
- **多账号隔离**：每个 AI 平台通过独立 Profile 隔离 Cookie / Storage / Cache，同一平台可同时登录多个账号
- **AI 应用多开**：同一平台支持同时打开多个独立实例，通过「复制」快速克隆配置
- **反检测指纹注入**：可自定义设备指纹，避免被平台识别为同一设备
- **自定义 AI Provider**：支持接入任意 OpenAI 兼容协议的 AI 服务

### 提示词注入

- **提示词库**：独立窗口管理提示词模板，支持跨窗口一键注入
- **三段注入**：提示词按「前缀 + 正文 + 后缀」三段组合，灵活适配不同平台
- **发送前预览**：Enter 发送时拦截，弹出预览浮层展示注入后的完整文本，确认后才发送
- **默认提示词**：自定义对话窗口支持默认提示词，新建对话时自动作为首条消息发送

### 交互体系

#### 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt+Space` | 一键呼出 / 隐藏主窗口（触发阈值可自定义，避免误触） |
| `Alt+Q` | 切换进阶面板显隐 |
| `Alt+V` | 后台语音输入（按住说话，松开发送；默认禁用，需在设置启用） |

#### 软件内快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt+1` ~ `Alt+9` | 切换到第 N 个标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 向前 / 向后循环切换标签 |
| `Ctrl+T` | 脱离当前标签为独立窗口 |
| `Ctrl+W` | 主窗口：关闭当前标签；独立窗口：关闭整个窗口 |
| `Esc` | 独立窗口：先关闭打开的浮窗（设置 / 抽屉 / 弹窗等），无浮窗时关闭窗口 |
| `F4` / `F5` / `F6` | 后退 / 刷新 / 前进 |
| `F10` | 切换主题 |
| `F12` | 切换窗口置顶 |
| `` ` `` / `~` / `?` | 呼出 / 关闭快捷键说明面板 |
| 长按 `Tab` | 切换底栏（展开 ↔ 收起） |
| `Ctrl+G` | 网页空间导航开关 |

#### 窗口与界面

- **多标签主窗口**：顶栏 + 标签栏 + 多 webview + 底栏应用抽屉，标签栏与底栏默认抽屉式收起，悬停展开
- **脱离窗口**：任意 AI 应用可脱离主窗口独立运行，支持置顶、最大化
- **桌面 / 移动 UA 切换**：窄屏自动切换移动端 UA，也可手动三态切换
- **三档 UI 缩放**：紧凑 / 中档 / 大号
- **AI 切换器按最近使用排序**：自定义供应商按最近使用时间排序，最常用的排在最前

### 随用随记

- **后台语音输入**：`Alt+V` 一键唤起，无需聚焦窗口即可语音提问，悬浮预览窗实时显示识别结果
- **灵感笔记浮窗**：随时记录想法，不影响当前对话
- **白板集成**：支持发送对话内容、网页截图到白板，整合多源信息
- **多引擎语音识别**：内置离线引擎优先，自动回退到命令行引擎、云端 API 或本地识别软件
- **实时音量波形**：录音过程可视化，60 秒超时自动结束

### 历史与对话

- **历史搜索**：消息级编辑删除、对话标题编辑、相邻重复消息合并显示，支持 JSON / DeepSeek 导出 / Markdown 多格式导入
- **自定义对话窗口**：会话导出（MD / JSON）、三档密度（紧凑 / 舒适 / 宽松）、代码块深浅主题、今日 token 用量显示
- **登录痕迹自动保存**：Web 对话数据主动捕获落库

### 免打扰屏蔽

- **自动隐藏干扰元素**：AI 平台的下载引导、升级横幅、原生弹窗（confirm / alert / prompt）
- **屏蔽规则管理**：按域名配置 CSS 隐藏或 JS 脚本，内置规则可禁用不可删除
- **弹窗白名单**：连续 3 次拒绝弹窗后自动提示加入白名单
- **网页空间导航**：方向键在页面元素间移动，`Ctrl+G` 开关

### 数据与隐私

- **跨设备数据迁移**：导出 / 导入完整数据包（含对话记录、登录状态和个性化设置），新设备导入后无需重新登录
- **缓存与下载管理**：缓存清理（手动 + 每日 / 每周 / 每月自动），仅清缓存保留登录；文件可下载到指定目录
- **文件拖拽导入**：将文件拖入窗口即可自动注入当前 AI 应用

### 外观与个性化

- **主题模式**：浅色 / 深色 / 跟随系统
- **平台主题色**：每个 AI 平台可自定义主题色，底栏切换器同步显示色点
- **顶栏按钮自定义**：6 组按钮按需显隐
- **关闭行为可选**：直接关闭或最小化到托盘

### 网络与代理

- **代理模式**：系统代理 / 直连 / 自定义
- **协议支持**：HTTP / SOCKS5，提供认证与地址绕过
- **连通性测试**：一键测试代理可用性
