# 工百窗 / SidekickAI

**免费、功能丰富、无缝融入电脑使用的 AI 入门工具。**

工百窗·概念版是 AI 执行框架（harness）之外、面向人的交互窗口：把 AI 网页、对话、笔记和白板放在桌面上，让提问、记录和整理自然衔接。

这是一份送给用户的礼物。软件免费提供，采用 MIT 许可，你可以自由使用、修改和分享。概念版专心做好工具，独立维护版本，所有公开发布均为正式版。

## 主要功能

- **AI 网页与多账号**：集中打开常用 AI 网页，为不同账号保留独立的登录环境。
- **自定义 API 对话**：接入自己的模型服务，管理对话并保存聊天记录。
- **AI资产**：统一整理已收纳的对话、提示词和资料，查看思考与历史修订，保存常用模板并快速调用；支持图片、PDF 和文本预览，以及可选的资料保留期限。
- **本地笔记**：记录文字、任务列表、代码和图片，搜索笔记内容，并将内容发送到 AI 或存为提示词。
- **白板**：用无限画布整理想法、绘图和放置截图，管理多块白板。
- **窗口与快捷键**：快速唤出、切换和置顶窗口，自定义常用操作的快捷键。
- **备份与恢复**：导出本地资料，在需要时恢复配置和已保存内容。

源码构建的绿色版保留应用内备份与恢复，不附带官方安装版的独立恢复工具及其运行时。

## 数据与使用

对话资产、笔记、白板、提示词和设置保存在本机，已保存的本地内容可离线使用。AI 网页和远程模型服务需要网络，以及相应的账号或接口配置；第三方服务的使用条件和费用由对应服务提供方决定。

启用 AI资产后，支持的 AI 页面与 API 对话会持续收纳内容；网页收纳范围取决于页面实际加载的内容。资料只自动保存用户上传、粘贴或拖入的附件，已有 AI 返回资料保留，可在「资料」中筛选并多选清理。收纳失败时请保留原页面，等待重试。资料原件获取失败后可重试，临时上传文件可能需要重新上传；仅导出对话 JSON 不会包含原件，迁移全部资料请使用完整备份。

## 下载与安装

下载 [0.1.5 正式版](https://github.com/LinCi853/SidekickAI/releases/tag/v0.1.5)，支持 Windows x64 和 ARM64。

- [安装版](https://github.com/LinCi853/SidekickAI/releases/download/v0.1.5/SidekickAI-Setup-0.1.5.exe)：安装后，从开始菜单或桌面快捷方式打开工百窗。
- [绿色版](https://github.com/LinCi853/SidekickAI/releases/download/v0.1.5/SidekickAI-Portable-0.1.5-win.zip)：完整解压后，直接运行对应架构目录中的 `SidekickAI.exe`。

下载后可按同一发布页的 [SHA-256 校验和](https://github.com/LinCi853/SidekickAI/releases/download/v0.1.5/SHA256SUMS.txt) 核对文件。安装版是官方独立构建的可选二进制产物；绿色版也可从本仓源码构建。

开发建议使用项目根目录的 `launch.bat`，按菜单提示操作。
