# 工百窗 / SidekickAI

**免费、功能丰富、无缝融入电脑使用的 AI 入门工具。**

工百窗·概念版是 AI 执行框架（harness）之外、面向人的交互窗口：把 AI 网页、对话、笔记和白板放在桌面上，让提问、记录和整理自然衔接。

这是一份送给用户的礼物。软件免费提供，采用 MIT 许可，你可以自由使用、修改和分享。概念版专心做好工具，独立维护版本，所有公开发布均为正式版。

## 主要功能

- **AI 网页与多账号**：集中打开常用 AI 网页，为不同账号保留独立的登录环境。
- **自定义 API 对话**：接入自己的模型服务，管理对话并保存聊天记录。
- **提示词库**：保存常用提示词模板，通过快捷键快速调用。
- **本地笔记**：记录文字、任务列表、代码和图片，搜索笔记内容，并将内容发送到 AI 或存为提示词。
- **白板**：用无限画布整理想法、绘图和放置截图，管理多块白板。
- **窗口与快捷键**：快速唤出、切换和置顶窗口，自定义常用操作的快捷键。
- **备份与恢复**：导出本地资料，在需要时恢复配置和已保存内容。

## 数据与使用

笔记、白板、提示词和设置保存在本机，已保存的本地内容可离线使用。AI 网页和远程模型服务需要网络，以及相应的账号或接口配置；第三方服务的使用条件和费用由对应服务提供方决定。
